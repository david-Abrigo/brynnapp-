# Brynn - Parlante de Pagos (Sitio Web Oficial y Políticas)

Sitio web oficial, landing page y documentos legales para la aplicación **Brynn - Parlante de Pagos**.

Desplegado en **Vercel** y **GitHub Pages**.

## Contenido:
* `index.html` - Página principal de presentación de la aplicación y funciones.
* `privacy_policy.html` - Política de Privacidad oficial para Google Play Store.
* `terms_of_service.html` - Términos de Servicio oficiales para Google Play y RevenueCat.
* `vercel.json` - Configuración de enrutamiento limpio para Vercel.
